How Integrate plugs into the existing run-pipeline.ts and run-batch.ts.

Pipeline Runner Changes

Current (3 stages)

bun run src/run-pipeline.ts book.epub
  --comprehend-provider kimi
  --extract-provider kimi

Output: single JSON to engine/output/{slug}.json

→

New (4 stages)

bun run src/run-pipeline.ts book.epub
  --comprehend-provider kimi
  --extract-provider kimi
  --integrate-provider kimi
  --embedding-provider openai
  --graph-dir engine/graph

Output: per-book JSON + shared graph in engine/graph/

New CLI Options

Flag Default Purpose
--integrate-provider kimi LLM for entity disambiguation + relation classification
--embedding-provider openai Embedding model provider
--embedding-model text-embedding-3-large Which embedding model to use
--graph-dir engine/graph Where the knowledge graph files live
--skip-integrate false Run only Parse → Comprehend → Extract (current behavior)
--rebuild-graph false Wipe graph and rebuild from all output/*.json files

Batch Runner Behavior

// run-batch.ts — new flow
for (const epub of BOOKS) {
  // Stages 1-3: same as before
  const tree = await parse(epub)
  const comprehension = await comprehend(tree, llmProvider)
  const extraction = await extract(comprehension, llmProvider)

  // Save per-book output (unchanged)
  saveOutput(`output/${slug}.json`, { metadata, comprehension, extraction })

  // Stage 4: Integrate into shared graph (NEW)
  const existingGraph = loadGraph('graph/')    // null if first book
  const updatedGraph = await integrate({
    atoms: extraction.atoms,
    metadata: tree.metadata,
    existingGraph,
    llmProvider: integrateProvider,
    embeddingProvider
  })
  saveGraph('graph/', updatedGraph)

  await delay(2000)  // rate limiting
}

Each book integrates incrementally. After all 8 books, engine/graph/ contains the complete knowledge graph. Running --rebuild-graph wipes graph/ and re-integrates from all output/*.json files sequentially.
