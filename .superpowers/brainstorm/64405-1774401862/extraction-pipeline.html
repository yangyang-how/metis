Extract Stage: Full Pipeline

One cheap-model call per section. ComprehensionMap guides what to look for.

Data Flow

Parse → Comprehend → Extract
FROM COMPREHEND
ComprehensionMap
• chapterType: "framework"
• structures: [...]
• sectionAnalyses: [...]
FROM PARSE
NormalizedChapter
• sections[].content
• raw text, tables, images
→
EXTRACT (per section)
1. Skip trivial sections (<3 blocks)
2. Build prompt with:
• Section content
• SectionAnalysis context
• All 17 frame type schemas
3. Call cheap model (Haiku)
4. Parse + validate atoms
5. Adjust confidence scores
→
OUTPUT

• CandidateAtom[]
• ProposedFrameType[]
• usage stats
• flagged atoms

Validation & Confidence Adjustment

Validation (lenient)
✓ Has frame type (core or proposed)
✓ Has at least 1 role filled
⚠ Missing optional roles → flag, keep
⚠ Empty conditions → flag, keep
✗ No frame type → reject
✗ Zero roles → reject
Confidence Adjustments
↑ +0.05 All roles filled
↑ +0.05 Has conditions
↑ +0.05 Frame type matches SectionAnalysis prediction
↓ −0.1 Missing required roles
↓ −0.1 Has validation flags
Clamped to [0.0, 1.0]
