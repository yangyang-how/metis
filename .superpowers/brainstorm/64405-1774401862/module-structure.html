How One Chapter Gets Extracted

extract() orchestration flow
1
Load frame registry
17 core types + any domain types from earlier chapters
2
Filter sections
Skip sections with <3 content blocks (front matter, headings-only, copyright)
3
For each section (sequential):
a. Build prompt: section content + SectionAnalysis context + full frame type schemas
b. Call cheap model (Haiku)
c. Parse JSON response into CandidateAtom[]
d. Collect any ProposedFrameTypes → register in registry
e. If section fails → log, skip, continue
4
Validate all atoms
Check frame types, roles, flag incomplete atoms, adjust confidence scores
5
Return ExtractionResult
All atoms + proposed types + usage stats + skipped sections + flagged atoms

Error Handling Philosophy

🟢
Section succeeds
Atoms extracted, validated, confidence adjusted. Normal path.
🟡
Section fails
Log error, skip section, continue to next. Zero atoms from this section.
🔴
Auth / config error
Fail immediately. No point processing more sections with bad credentials.
Same philosophy as Parse and Comprehend: partial results are better than no results.
