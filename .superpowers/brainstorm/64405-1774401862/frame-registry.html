Frame Type Registry

17 core types ship with Metis. Domain types are proposed during extraction.

How It Works

Extraction Flow
1. Registry Loaded
17 core types pre-loaded at startup. Each type has a name, role schema, and description.
→
2. Section Extracted
Cheap model extracts atoms using known types. If knowledge doesn't fit, it proposes a new type.
→
3. Type Registered
New type validated (name, ≥2 roles, description), deduplicated, and added to registry. Available for future sections.
